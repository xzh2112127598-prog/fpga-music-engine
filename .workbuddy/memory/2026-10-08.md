## 板卡身份纠错（重要）

此前长期笔记里记的 **Tang Nano 20K / GW2AR-LV18 / 27MHz 是错的**。
真实板卡：**Sipeed Tang Primer 25K**，FPGA = **GW5A-LV25MG121NC1/I0**，
**Device Version A**，板载 **50MHz 有源晶振**。

已全仓库修正（12 个文件）并推送。关键影响：
- i2c_master 的 `DIV_RAW` 用 ceil 除法，50MHz 下 SCL = 128 系统钟 = 390.6kHz（合规）
- 板载只有 **3 个 LED**（L6 / D7 / E8），不是 4 个
- 板载 2 个按键，只用 K6（低有效）
- clk = E2

## 拿到 Gowin 下板链路（首次打通）

- Gowin EDA **V1.9.11.03 Education 免 license**（官方例程 README 明确说明）
- 器件内部编号：**gw5a25a-002**（Version A）；Version B = gw5a25b-003
- 官方例程里的 `GW5A-LV25MG121NES` 是另一颗料，**不要照抄**
- 引脚来源：Sipeed 官方例程 `pmod_led/src/pmod_led.cst`

### 必踩的坑：三个专用引脚

E2=CPU、D7=DONE、E8=READY 都是专用脚，不开复用开关 PnR 必报
`PR2017 / PR2028 "dedicated pin"`。解法（实测二分确认）：

```tcl
set_option -use_cpu_as_gpio 1    # 这一项解决 clk(E2)；sspi/mspi 不需要
set_option -use_done_as_gpio 1   # led[1](D7)
set_option -use_ready_as_gpio 1  # led[2](E8)
```

### 命令行一键编译（Gowin 自带 gw_sh.exe，不算第三方工具）

```bash
cd rtl/fpga_practice && "D:/Gowin/Gowin_V1.9.11.03_Education_x64/IDE/bin/gw_sh.exe" < build_led.tcl
```
流程名是 `run all` / `run pnr`（不是 `run synth`）。产物 `impl/pnr/led_top.fs`。

实测结果：LUT 172/23040，FF 93，建立时间余量 **+15.573ns**（周期 20ns），
五个引脚全部落位，`.fs` 5.96MB 生成成功。

### gw_sh 用法备忘

- `open_project x.gprj` / `set_option -xxx 1` / `run all` / `saveto f` / `exit`
- **XML 的 .gprj 存不下 set_option**（试过 Options/OptionList/各种变体都不行），
  所以选项只能走脚本；GUI 里则在 Project → Configuration → Place & Route 勾选
- `saveto` 导出的是 Tcl 格式，里面有 `set_device <pn> -device_version A`
- rst_n 不约束引脚会被引到随机脚，改用内部上电复位规避
