## 三、ModelSim 仿真操作（通用）

1. 新建 Project，把对应练习的两个 `.v` 都 Add 进来 → Compile All（无报错）；
2. Library 窗口找到 `tb_xxx`，右键 Simulate；
3. 把信号 Add Wave，点 Run（或按 tb 里注释 run 指定时间，如 `run 10ms`）；
4. 波形不符合预期 → 改代码 → 重新 Compile → Restart 再 Run。

## 五、思考题（9.29 做，直接关系赛题 10ms 延迟）

练习 4 是"稳定 10ms 才确认"的标准消抖——如果钢琴按键也这样，
声音至少晚 10ms 出来，正好顶满红线。怎么改成**"按下立刻响"**？

> 提示：在 `S_IDLE` 一检测到 `key_in` 就立刻发出 `key_press` 触发音符，
> 状态机只负责"事后确认是不是误触"，发现是抖动再发一个取消指令；
> 释放方向仍正常消抖。国庆做钢琴模块时就用这个"乐观消抖"版本。

## 六、常见坑

- 时序逻辑里误用 `=` → 仿真诡异、时序全乱，记住 `<=`；
- 用分频信号当新模块的 clk（造时钟）→ 时序约束和毛刺问题，一律改用使能脉冲；
- `CLK_FREQ` 参数不改成实际板子值 → 心跳频率全错（Tang Primer 25K 是 50MHz）；
- `.cst` 引脚号照抄模板不查原理图 → 下载后灯不亮/按键无效。
