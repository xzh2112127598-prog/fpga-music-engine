# 演奏数据包协议 v1.0

- 版本：v1.0（冻结日期：2026 年 10 月 5 日，全队联调确认）
- 状态：已冻结（此后任何修改须队长确认并全队同步）
- 用途：PC ↔ FPGA、MATLAB ↔ 串口播放器之间传递乐器演奏事件

## 1. 设计目标

1. 一个数据包可携带任意乐器事件（钢琴/鼓/笛子/吉他共用）。
2. 带绝对时间戳，接收端按时间戳调度，容忍乱序与掉帧（丢帧不卡、不爆音）。
3. 数据以 int16 为主。

## 2. 帧格式（12 字节定长，小端）

| 字节  | 字段    | 值/编码                                                          | 说明                         |
| --- | ----- | ------------------------------------------------------------- | -------------------------- |
| 0   | 帧头1   | 0xAA                                                          | 固定                         |
| 1   | 帧头2   | 0x55                                                          | 固定                         |
| 2   | 乐器/事件 | bit7–6 乐器ID（00钢琴/01鼓/10笛子/11吉他）；bit4 事件（0按下/触发，1松开）；bit3–0 通道 | 四乐器共用一包                    |
| 3   | 保留    | 0x00                                                          | 扩展（滑音等）                    |
| 4–5 | 时间戳   | uint16，单位 5ms                                                 | 绝对时刻，接收端按此调度；范围 0–327.675s |
| 6–7 | 音符/参数 | int16：钢琴=MIDI 音高（60＝中央C）；鼓=鼓件编码（0底鼓/1军鼓/2闭镲/3开镲/4桶鼓）          | int16 核心数据                 |
| 8–9 | 力度    | uint16（0–65535）                                               | 钢琴映射音量/亮度；鼓映射音量/亮度         |
| 10  | 音长    | uint8，单位 0.05s（0–255→12.75s）                                  | 0 表示"按住直到松开事件"             |
| 11  | 校验    | 前 11 字节异或                                                     | 防误帧                        |

## 3. 示例帧

钢琴按下中央 C（MIDI 60）、力度 32768、音长 0.5s、时间戳 1000ms：

```
AA 55 00 00 C8 00 3C 00 00 80 0A <校验>
```

校验计算：把前 11 个字节逐字节异或，结果填第 12 字节。

## 4. 校验算法（MATLAB）

```matlab
f(12) = 0;
for k = 1:11
    f(12) = bitxor(f(12), f(k));
end
```
