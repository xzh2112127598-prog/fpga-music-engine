## 0. 一分钟总览

```
┌──────────────── Tang Primer 25K Dock（上边缘三个 PMOD 排针）────────────────┐
│                                                                             │
│   [ J6 最左，靠 USB-A ]      [ J5 中间 ]           [ J4 最右 ]               │
│   └── ES8388 全套 9 根线     └── MPU6050 4 根线    └── 空闲                  │
│                                                                             │
│   [USB-C：下载 + 虚拟串口]   [LED4=D7][LED3=E8]   [S1=H11][S2=H10][MODE]    │
└─────────────────────────────────────────────────────────────────────────────┘

每条 I2C 总线现在各走各的排针，互不打架：
   ES8388  I2C  -> J6 的 G5(SCL) / F5(SDA)   ⚠️ 需外部 4.7kΩ 上拉（见 §6）
   MPU6050 I2C  -> J5 的 A10(SCL) / A11(SDA) ✔ 模块自带 2.2kΩ 上拉
```

## 1. 三个 PMOD 排针的引脚定义（通用）

三个排针（J6 / J5 / J4）结构一样：**pin1/2 = 3V3、pin3/4 = GND，pin1 = 方形焊盘**。
pin1 在靠 USB-A 那一端（J6 的最左侧）。其余 8 脚是 FPGA 的普通 IO：

| PMOD | pin5 | pin6 | pin7 | pin8 | pin9 | pin10 | pin11 | pin12 |
|---|---|---|---|---|---|---|---|---|
| **J6** | H5 | J5 | H8 | H7 | G7 | G8 | F5 | G5 |
| **J5** | L5 | K5 | K11 | L11 | E11 | E10 | **A11** | **A10** |
| **J4** | C11 | C10 | B11 | B10 | D11 | D10 | G11 | G10 |

> ⚠️ 排针名（J6/J5/J4）和 FPGA 球名（J5/H5/…）是两码事，别混。比如 J6 的 pin6 恰好是 FPGA 球 J5。

## 2. ES8388 声卡 —— 全部走 J6（9 根线）

模块排针是 **J0（TSW-112-07-G-D，2×12 = 24 脚，丝印 1 = 方形焊盘）**，奇数脚基本悬空不用。

| ES8388 模块 J0 脚 | 信号 | J6 引脚 | FPGA 球 | 方向 | 断了的后果 |
|---|---|---|---|---|---|
| **23** | 3.3V | pin1 或 pin2 | — | 供电 | 绿灯不亮 |
| **24 或 21** | GND | pin3 或 pin4 | — | 地 | 绿灯不亮 |
| **12** | I2S_MCLK | pin5 | **H5** | FPGA → 模块 | ★ 芯片不起振，完全无声 |
| **10** | I2S_SCLK | pin6 | **J5** | 模块 → FPGA | BCLK 回不来（灯快闪） |
| **6** | I2S_LRCK | pin7 | **H8** | 模块 → FPGA | LRCK 回不来（灯常灭） |
| **8** | I2S_SDIN | pin8 | **H7** | FPGA → 模块 | 芯片正常但无声 |
| **4** | I2S_SDOUT | pin9 | **G7** | 模块 → FPGA | 影响录音，不影响出声 |
| **14** | I2C_SCL | pin12 | **G5** | FPGA → 模块 | 配置写不进去 |
| **16** | I2C_SDA | pin11 | **F5** | 双向（开漏） | 配置写不进去 |

要点：

- **ES8388 工作在主机模式**（R8=0x80）：BCLK/LRCK 由**芯片**产生回给 FPGA，FPGA 只负责给它 MCLK。
- **MCLK = 12.288MHz**，由 FPGA 的 `PLLA` 原语产生（50MHz ÷1 ×1 ×14.5 ÷59 = 12.288136MHz，+11ppm，见 `rtl/es8388/es8388_audio_pll.v`）。
- **I2C 地址 = 0x10**（芯片 CE 脚已焊死接地，不用猜）。
- 耳机插 **J1**（别插 J2 LINE IN / J3 MIC）。
- ⚠️ **CE 接地、板上原理图标了 2.00kΩ 上拉，但实测那对电阻没起作用**（见 §6）。

## 3. MPU6050（GY-521）—— 走 J5（4 根线）

| GY-521 | J5 引脚 | FPGA 球 | 说明 |
|---|---|---|---|
| **VCC** | pin1 或 pin2 | — | 3.3V，**不能接反**（会烧） |
| **GND** | pin3 或 pin4 | — | |
| **SCL** | pin12 | **A10** | |
| **SDA** | pin11 | **A11** | |
| XDA / XCL / AD0 / INT | **不接** | — | AD0 模块上已下拉 → 地址 0x68 |

要点：

- 量程必须设 **±16g**（`ACCEL_CONFIG = 0x18`），默认 ±2g 一敲就爆表、力度全丢。
- ±16g 下 **1g = 2048 LSB**。
- 采样率 **1000Hz**（代码里已扣掉 I2C 事务耗时，否则实际只有 823Hz）。
- 模块自带 **2.2kΩ 上拉**，所以 J5 这一路不用外加电阻。
- **为什么要搬到 J5**：ES8388（0x10）和 MPU6050（0x68）都是 I2C 从机，两个主机同时驱动同一组引脚会打架。与其写总线仲裁，不如各走一条总线。

## 6. ⚠️ 当前待解决的一个硬件问题：ES8388 I2C 缺上拉

**现象**：MPU6050 搬到 J5 后，ES8388 配置写不进去（耳机里是噪声 + 灯快闪）。

**根因**：ES8388 的 I2C 一直是靠 **MPU6050 模块板上的 2.2kΩ 上拉**撑着的（它俩之前在同一个排针上）。搬走后上拉没了。FPGA 内部上拉已开（`PULL_MODE=UP`）但太弱，I2C 也已从 250kHz 降到 50kHz，仍不够。

**解决（30 秒）**：加两个外部上拉电阻：

| 电阻 | 一端 | 另一端 |
|---|---|---|
| 4.7kΩ | **J6 pin12**（G5，SCL） | **J6 pin1 或 pin2**（3V3） |
| 4.7kΩ | **J6 pin11**（F5，SDA） | **J6 pin1 或 pin2**（3V3） |

电阻腿直接插进排针孔即可，不用焊。**没有 4.7kΩ 就用 2.2k ~ 10k 之间任何值。**

## 7. 交接时必须知道的坑（都踩过，写进了代码注释）

1. **板载按键必须在 `.cst` 里显式 `PULL_MODE=DOWN`**——只写 `IO_LOC` 会浮空，表现是"按一次有效、之后怎么按都没用"。
2. **多按键不能写成 `(~keyA) | keyB` 这种 OR 电平再消抖**——一个脚不是按键、电平固定时会把 OR 结果永久拉高，其余按键全失效。正确做法是**每个脚各自独立 `debounce_fsm`，再 OR 各路的脉冲**。
3. **I2C 总线必须有上拉**，而且"之前能工作"可能是别的模块在帮忙——搬走任何挂在总线上的模块，都要重新确认上拉还在。
4. **`i2c_dri` 不校验 ACK**（参考工程遗留）——配置失败时 `cfg_done` 照样亮，会骗人。我补了 `cfg_ack_err` 标志，但还没让它阻止 `cfg_done`（待修）。
5. **敲击检测算法必须三边同步**：MATLAB `main_drum_engine.m` / `tools/ref_hit.py` / `rtl/src/hit_detector.v`，对拍靠 `tools/diff_trace.py`。
6. 合规红线：**全程纯硬件合成，工程内不存在任何预录 PCM 音源**。
