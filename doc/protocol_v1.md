## 已知约定（附录 B · 模板 B3）

12 字节定长帧，串口 115200 波特率：

| 字节 | 含义 |
|---|---|
| 0 | 帧头 `0xAA` |
| 1 | 帧头 `0x55` |
| 2 | 高 2 位 = 乐器 ID；bit4 = 事件；bit3-0 = 通道 |
| 3 | 保留 |
| 4-5 | 时间戳（单位 5 ms） |
| 6-7 | 音符（int16） |
| 8-9 | 力度（uint16） |
| 10 | 音长（单位 0.05 s） |
| 11 | 校验：前 11 字节异或 |

## 填写要点

- 乐器 ID 编码需与 `params/drum_params.md` 的鼓件类型对齐
  （建议 1=kick、2=snare、3=hihat、4=piano，与 `voice_render` 的 type 一致）
- 时间戳调度机制要说明「防掉帧」策略
- 验收：连续 200 帧无丢帧错帧（校验和全对）
