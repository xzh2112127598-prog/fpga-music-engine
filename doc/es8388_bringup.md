# ES8388 声卡上板指南（demo_es8388）

> 目标：耳机里听到 FPGA 自己合成的《小星星》旋律，打通  
> 「纯硬件合成 → 数字音频 → ES8388 → 耳机」整条链路。  
> 这是队员 B 三鼓件出声的前置必经步骤。

## 1. 为什么是 ES8388 而不是"DAC"

ES8388 是**编解码器（codec）**，不是纯 DAC：上电不会自己出声，  
必须先用 I2C 写约 24 个寄存器（打开电源、配 I2S 格式、配音量），  
然后 FPGA 再通过 I2S 串行口送样本才有声音。

好消息：它和我们 MPU6050 用**同一种 I2C 总线**，地址 0x10（MPU6050 是  
0x68），可以共用一根总线；I2C 配置阶段**不需要 MCLK 也能工作**。

参考代码来自指导老师给的 `voice_changer_phone`（安路 EG4S20 工程），  
6 个 Verilog 文件是纯通用逻辑，已原样移植到本仓库 `rtl/es8388/`，  
只重写了时钟部分（安路的 EG_PHY_PLL → 高云 GW5A 的 PLLA 原语）。

## 2. 模块排针定义（已从原理图核实）

模块板上是 **J0：TSW-112-07-G-D，2×12 排针（24 脚）**，  
丝印 **1 = 方形焊盘**。原理图截图见  
`doc/img/es8388_module_header.png`（来自《ES8388声卡原理图.pdf》）。

|                    排针脚 | 网络名       | 方向（相对 FPGA） | 接到 Tang Primer 25K Dock J6 |
| ---------------------: | --------- | :---------: | -------------------------- |
|                     23 | 3.3V      |      —      | J6 pin1 或 pin2（3V3）        |
|                24 或 21 | GND       |      —      | J6 pin3 或 pin4（GND）        |
|                     14 | I2C_SCL   |      →      | J6 pin12（FPGA 球 G5）        |
|                     16 | I2C_SDA   |      ↔      | J6 pin11（FPGA 球 F5）        |
|                     12 | I2S_MCLK  |      →      | J6 pin5（FPGA 球 H5）         |
|                     10 | I2S_SCLK  |      ←      | J6 pin6（FPGA 球 J5）         |
|                      6 | I2S_LRCK  |      ←      | J6 pin7（FPGA 球 H8）         |
|                      8 | I2S_SDIN  |      →      | J6 pin8（FPGA 球 H7）         |
|                      4 | I2S_SDOUT |      ←      | J6 pin9（FPGA 球 G7）         |
| 其余（1/2/5/…/20/22 等奇数脚） | 悬空        |      —      | 不接                         |

共 9 根杜邦线（电源 2 + 地 1 + 信号 6）。  
**注意 SCLK/LRCK/SDOUT 的箭头方向：ES8388 被配置成主机（R8=0x80），  
BCLK 和 LRCK 是芯片产生后送回 FPGA 的，别接反。**

- 模块 I2C 已板载 2.00kΩ 上拉（R17/R18），每个信号线上还有 10Ω 串阻。
- 模块上**红色 LED 是电源灯**，通电常亮 = 供电 OK，先看它。
- 模块插座：J1 耳机（3.5mm）、J2 LINE IN、J3 麦克风、PH2.0-2P 喇叭。  
  本 demo 只用 **J1 耳机**。

## 3. 时钟方案（GW5A 专属坑）

GW5A(Arora-V) 的 PLL 原语和 GW1N/GW2A **不同名**：

| 尝试                   | 结果                     |
| -------------------- | ---------------------- |
| `rPLL`（GW1N/GW2A 用法） | EX3937 unknown module  |
| `PLL`（UG306 文档里的原语名） | RP0008 no PLL resource |
| **`PLLA`**           | ✅ 综合通过                 |

PLLA 频率公式：`Fout = CLKIN/IDIV × FBDIV × MDIV / ODIV0`，  
且 **PFD 必须在 19~87.5MHz**、**VCO 700~1400MHz**。

本配置：`50MHz ÷1 ×1 ×14.5 ÷59 = 12.288136MHz`（+11.0ppm，与参考  
工程的安路板同解；fs = 48000.53Hz）。MDIV 支持 1/8 小数（14.5 =  
14 + 4/8）。曾找到精确 12.288MHz 的解（÷5×6×16÷78.125），但  
PFD=10MHz 低于下限，被拒。

DDS 频率字按真实 fs 算：`FTW = round(f × 2^32 / 48000.53)`。

## 5. 现象与诊断

| 灯                | 含义                             |
| ---------------- | ------------------------------ |
| POWER（LED1/LED5） | 电源，常亮（不受 FPGA 控制）              |
| **LED4（D7）**     | PLL 锁定，常亮 = MCLK 12.288MHz 已产生 |
| **LED3（E8）**     | 链路状态，三档（见下）                    |

### E8 五档（没有耳机时靠它判断）

| E8 表现         | 含义                                 | 该做什么                                  |
| ------------- | ---------------------------------- | ------------------------------------- |
| **慢闪 ~1.5Hz** | 24 个寄存器还没写完                        | 正常只出现一两秒；一直慢闪说明 I2C 卡死，查 SDA/SCL     |
| **中闪 ~6Hz**   | **芯片没应答**（固件每 0.5s 自动重试）            | 查 3.3V/GND；查 SCL/SDA 是否接反或接触不良（模块 14/16 脚） |
| **快闪 ~24Hz**  | 芯片应答了、寄存器写进去了，但 **BCLK 没出来**        | 查模块 10 脚(SCLK)→J6 pin6(J5)          |
| **常灭**        | BCLK 有、但 **LRCK 没跳动**               | 查模块 6 脚(LRCK)→J6 pin7(H8)           |
| **常亮**        | 24 字节全部 ACK 正常 + BCLK/LRCK 都在跳       | 链路已通，插耳机就该有声                          |

### D7 在链路通了之后会改显"当前档位"

| D7            | 含义                       |
| ------------- | ------------------------ |
| 常亮            | 档 0：满幅方波                  |
| 慢闪 ~1.5Hz     | 档 1：《小星星》               |
| 灭             | 档 2：静音                   |

链路**没**通的时候 D7 还是显示 PLL 锁定（常亮 = MCLK 正常）。
这样不用去盯按键那 0.25 秒的快闪，档位是持续可见的。

⚠️ “常灭”这一档是 2026-10-11 补的。之前只看 BCLK 不看 LRCK，
结果 LRCK 没接好时会出现**“三个灯全亮但耳机完全静音”**——
因为 `lrc_edge` 恒为 0 → DDS 不推进、`dac_data_t` 恒 0 → 一路静音，
而 BCLK 还在跳，灯照样全亮，非常具有迷惑性。

NACK 自动重试：接线修好后**不用重新下载**，固件每 0.5s 重跑一轮 24 寄存器配置，
最多 1 秒内 E8 就会自动跳到正确状态。

⚠️ 参考工程的 `i2c_dri.v` 原本**完全不采样 ACK**，所以"没接芯片"和  
"配置成功"在灯上表现一样——这就是为什么本次专门补了 ACK 检测  
（`i2c_dri.v` 第 9 位采样 SDA）+ BCLK 心跳看门狗。现在的灯是可信的。

### 没耳机怎么进一步确认（按推荐顺序）

1. **找任何 3.5mm 设备**：手机耳机、电脑音箱 AUX 线、实验室的耳机。  
   这是最快最直接的。
2. **万用表交流档量耳机座 J1**：尖端（左声道）对地应有几十~几百 mV  
   交流电压（440Hz 在部分万用表 40–400Hz 量程边缘，量不到也不代表失败）。
   播旋律时电压会随音符起伏，比固定音更好认。
3. **示波器看三个点**（最硬核）：模块 6 脚 LRCK 应为 48kHz 方波、  
   10 脚 BCLK 约 3.07MHz、8 脚 SDIN 应有密集跳变。有这三个波形 = 一定有声。
4. **Gowin 在线逻辑分析仪（GAO）**：抓 SDA/SCL 看 ACK 位是否为低。

### 两个键都没反应？用 `key_probe` 直接测物理事实

`led_top.v` 时代记录过“K6 低有效、H11 高有效”，但 demo 按下去毫无反应，
说明这个记录**可能记错了球号或极性**。与其猜，不如直接测：

双击 `rtl/fpga_practice/build_key_probe.bat`，下载 `impl/pnr/key_probe.fs`。
这个固件什么都不干，只把按键原始电平接到灯上：

| 灯            | 显示什么     |
| ------------ | -------- |
| **LED4（D7）** | K6 的原始电平 |
| **LED3（E8）** | H11 的原始电平 |

**逐个按住**板上的按键（按住不放），看哪颗灯动、往哪边动：

| 现象    | 结论                 |
| ----- | ------------------ |
| 灯从灭变亮 | 该键按下 = 1（高有效）      |
| 灯从亮变灭 | 该键按下 = 0（低有效，有上拉）  |
| 灯完全不动 | **这个球号不是按键**，得换球号  |

把结果告诉我，我改 CST。第 3 个键多半是 BL616 调试器的 BOOT 键，
不接 FPGA，按了本来就没反应。

### 三档音源（按**任意一个**板载按键循环切换）

> ⚠️ 板载按键有 **2 个**（K6 低有效、H11 高有效），丝印不印球号，
> 所以固件里两个都接了、并联使用（`key_high = (~key) | key2`），
> **按哪个都行**。2026-10-11 之前只接了 K6，按另一个键毫无反应，
> 一度被误判成"切档没生效"。

| 档位      | 内容                                                          | 用途                                   |
| ------- | ----------------------------------------------------------- | ------------------------------------ |
| **0（上电默认）** | **满幅 1kHz 方波**，打到 ±满量程(±0x7FFFFF)，响 0.25s 停 0.75s（滴滴滴）      | **链路探针**：完全绕开 DDS/ROM/包络，只回答“数字音频能不能到耳朵” |
| **1**   | 《一闪一闪亮晶晶》C 大调 120BPM，42 音 / 48 拍，24 秒一轮，5ms 起音 + 21ms 收尾，像八音盒 | 确认音源逻辑（DDS + 包络 + 音符表）               |
| **2**   | 全 0 静音                                                      | 对比“到底是不是真的有声音”                       |

**排查口诀：先听档 0，再听档 1。**

- 档 0 听不到 → 是**硬件**（接线 / 插孔 / 编解码器），跟代码无关；
- 档 0 听得到、档 1 听不到 → 是**音源逻辑**（只可能是 DDS 或包络），代码问题。

**按键确认反馈**：按下后 0.25 秒内 **D7 和 E8 互补快闪 3 下**（约 12Hz），
然后恢复成正常的链路显示。有了这个就能一眼分开两种"按了没变化"：

- **灯闪了** → 按键和切档都生效了，那"没变化"是音源本身的问题；
- **灯不闪** → 按的键没接到，或者消抖没过（换另一个键试）。

方波档已在 `tb_sq.v` 里做过仿真对拍：样本 0~11999 严格在
`0x007FFFFF` / `0xFF800000` 之间跳，12000 起归零，异常数 0，
I2S 数据线 47997 次翻转。所以这档在上板前就已证明是对的。

### “耳机功率不够”吗？——不是

ES8388 的 LOUT1/ROUT1 是**专用耳机驱动**（不是 LINE OUT），设计负载
16Ω/32Ω，推普通手机耳机绰绰有余。而且档 0 是**满量程**输出，
比任何正常音乐都响。所以“耳机推不动”这条可以排除。

真要怀疑耳机本身，只查三件事：

1. **插的是 J1（耳机）还是 J2（LINE IN）/ J3（MIC）**——插错孔是最常见原因；
2. **插头是否插到底**（有“咔”的一声）；
3. **耳机是不是带麦的四段插头**——换成普通三段耳机试。

### E8 常亮却还是没声音，按这个顺序查

| 顺序 | 查什么                                            |
| -- | ---------------------------------------------- |
| 1  | 耳机插 J1 了吗？插到底了吗？（见上）                           |
| 2  | 按 S1 切到档 0（满幅方波）再听——排除音源逻辑                     |
| 3  | 模块 8 脚(SDIN) → J6 pin8(H7) 这根线有没有接/接错（数据线，最容易漏） |
| 4  | 模块 4 脚(SDOUT) → J6 pin9(G7)（本 demo 不用，但接错不影响出声） |
| 5  | 万用表交流档量 J1 尖端对地：档 0 响的 0.25s 内应有几百 mV 跳变       |

### ⚠️ 上电时序

**模块先通电（灯亮）→ 再给 FPGA 下载**。中途拔过模块的
电源线就必须重新下载位流，否则芯片掉回未配置状态、一直静音。
（新版固件有 NACK 自动重试，重试成功后能自愈，但重新下载更省事。）
