# 电子鼓 `demo_drum`（MPU6050 敲击 → 鼓件合成 → ES8388 出声）

链路验证（`demo_es8388`）通过之后的真正功能版本。敲一下就能听见鼓声。

## 1. 接线

### ⚠️ MPU6050 要搬到 J5

ES8388（0x10）和 MPU6050（0x68）都是 I2C 从机，**两个主机同时驱动同一组
引脚会打架**。与其做总线仲裁，不如让它们各走一条总线：

| 模块      | 排针            | SCL             | SDA             | 供电                |
| ------- | ------------- | --------------- | --------------- | ----------------- |
| ES8388  | **J6**（不动）    | pin12 = G5      | pin11 = F5      | pin1/2=3V3, pin3/4=GND |
| MPU6050 | **J5**（搬过来）   | pin12 = **A10** | pin11 = **A11** | pin1/2=3V3, pin3/4=GND |

三个排针结构都一样：pin1/2 = 3V3、pin3/4 = GND，**pin1 = 方形焊盘**。
J5 是上边缘**中间**那个排针（J6 最左靠 USB-A、J4 最右）。

GY-521 的 XDA / XCL / AD0 / INT **全部不接**，模块自带 2.2k 上拉，地址 0x68。
**VCC 和 GND 不能接反**，会烧模块。

ES8388 那一侧的接线与 `doc/es8388_bringup.md` 完全一致，**不用动**。

## 3. 现象

| 灯                 | 含义                                     |
| ----------------- | -------------------------------------- |
| **LED4（D7）**      | ES8388 链路。常亮 = OK；慢闪 = 还没配好          |
| **LED3（E8）**      | **敲一下亮 150ms**（确认敲击被检测到）；MPU6050 ACK 错误时改成快闪 |

操作：**用手指敲 MPU6050 模块本身，或者敲它所在的桌面**。

- 敲下去 E8 亮 → 加速度真的读到了、敲击检测触发了
- 耳机里同时出鼓声 → 全链路通

## 4. 三鼓件怎么分的

`hit_detector` 用峰值窗内 `ay` 的均值判方位（左/中/右），映射成：

| hit_type | 鼓件   | 音源            | 衰减         |
| -------- | ---- | ------------- | ---------- |
| 1        | 底鼓   | 60Hz 正弦        | tau≈21ms   |
| 2        | 军鼓   | 180Hz 正弦 + 白噪声 | tau≈10ms   |
| 3        | 镲    | 白噪声           | tau≈43ms   |

力度 `hit_vel`（0~127）直接乘进幅度，敲得重就更响。
量程必须是 **±16g**（`ACCEL_CONFIG=0x18`），±2g 一敲就爆表、力度全丢。

## 5. 当前限制（后续要补）

1. **单 voice**：一次只响一个鼓，后敲会直接打断前敲。要做"同时响"得扩成
   多个 voice 再相加（注意加完要限幅，否则叠加溢出会有爆音）。
2. **音色还比较简陋**：真实底鼓有音高下滑（pitch envelope），军鼓/镲需要
   带通滤波的噪声。下一步按 `sim/teamB/drum_sim_matlab/` 的 MATLAB 模型对齐。
3. **参数没跟 MATLAB 对拍过**：衰减系数、混合比例目前是手调的，
   后面要按工程铁律走 `tools/diff_trace.py` 三边同步。
4. `key_s1/key_s2` 已接进来但**还没分配功能**（预留切鼓组 / 调灵敏度）。
